# MediAssist AI

An AI-powered healthcare assistant that helps users understand medical reports and blood smear images.

## Features

- CBC Report Analysis
- OCR for Medical Reports
- Blood Smear Image Analysis
- AI Health Explanation
- Medical Chatbot
- Disease Risk Prediction
- PDF Report Generation

## Tech Stack

- Frontend: Next.js
- Backend: FastAPI
- Database: PostgreSQL
- AI: PyTorch
- OCR: EasyOCR/PaddleOCR
